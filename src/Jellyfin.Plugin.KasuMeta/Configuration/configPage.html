For each language, the first provider with a value wins and the next ones fill what it lacks: a title TVDB doesn't have in Spanish comes from TMDB. A provider is used only when it is listed here and its key is set (AniList needs none). Changing this fetches the library again, one request per item and provider.

Genre and tag dictionary

TMDB names genres in many languages; every other genre and tag arrives in English. Translate those terms here, once for the whole library: readers see them right away, with no re-fetch. A translation for a bare language (es) serves all its regions. Terms you leave empty stay in English.

A BCP-47 code, e.g. es or es-MX.
